# Contributing to Hisabna

Hisabna is licensed under Apache-2.0.

## Developer Certificate of Origin (DCO)

Every commit must carry a `Signed-off-by` line certifying that you wrote the
change or have the right to submit it under the project licence
(https://developercertificate.org/). Add it with `git commit -s`:

    Signed-off-by: Your Name <you@example.com>

Commits without a sign-off will not be merged.

## Development

- Node 22 (see `.nvmrc`) and pnpm.
- `pnpm install`, then `pnpm lint`, `pnpm typecheck`, `pnpm test`.
